# Logos — Brand Identity Assets

> **Purpose:** WildNest Studio logos, watermarks, end cards, and channel branding.

## What Belongs Here

- WildNest Studio logo (horizontal, stacked, icon-only variants)
- YouTube channel banner and profile icon
- Video end card template (3D animated callout)
- Watermark overlay for in-video branding
- Social media profile images and cover photos

## File Naming

```
LOGO_[VARIANT]_[COLOR]_V[VER].[ext]
Example: LOGO_HORIZONTAL_DARK_V01.png
```
