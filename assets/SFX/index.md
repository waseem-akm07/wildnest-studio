# SFX — Sound Effects & Foley Library

> **Purpose:** Physical foley sounds, environmental audio, and character non-verbal vocal banks.

## Categories

### Character Non-Verbal Vocals (8 sounds per character)

Each character has a locked set of 8 non-verbal vocalizations that remain **identical across all global dubs:**

| Sound | Description |
| :--- | :--- |
| Squeak | Short, high surprise burst |
| Gasp | Sharp inhale for shock moments |
| Groan | Low rumble of frustration or exhaustion |
| Chirp | Quick happy approval |
| Hum | Casual content sound while working |
| Grunt | Physical effort during labor |
| Sigh | Deep exhale of relief or resignation |
| Giggle | Light, warm laugh for joy beats |

### Physical Foley

- Tube corridor *thwips* and *squeaks*
- Water bottle *drip-drip-splash* sequences
- Cotton-ball *poof* landings
- Button *clink-clink* footsteps
- Twist-tie *crinkle* sounds
- Wood shavings *rustle* ambience

## File Naming

```
SFX_[CATEGORY]_[NAME]_V[VER].wav
Example: SFX_FOLEY_TUBE_THWIP_V01.wav
Example: SFX_VOCAL_BARNABY_SQUEAK_V01.wav
```
