> **Purpose:** Approved music stems, ambient background tracks, and tension cues.

## Audio Standards

| Parameter | Standard |
| :--- | :--- |
| Tempo (baseline) | 100–120 BPM cozy ambient |
| Tempo (tension) | 130–150 BPM escalating during ticking clock |
| Format | WAV 48kHz / 24-bit stereo |
| Loudness target | -14 LUFS integrated |

## What Belongs Here

- Cozy ambient baseline loops (Lobby, Spa, Kitchen)
- Tension escalation cues (ticking clock sequences)
- Comedy sting effects (pratfall hits, slide whistles)
- Victory/resolution warm cues
- End card music bed

## File Naming

```
MUSIC_[MOOD]_[BPM]BPM_V[VER].wav
Example: MUSIC_COZY_110BPM_V01.wav
```
