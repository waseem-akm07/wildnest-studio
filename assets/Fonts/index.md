## Typography Standards (from ART-001)

| Usage | Font Family | Style |
| :--- | :--- | :--- |
| Thumbnails | Rounded 3D bold sans-serif | Yellow with dark outline, max 2 words |
| Subtitles | Clean white sans-serif | 80% black translucent backing, 37 chars/line max |
| Brand / Titles | Custom WildNest display font | Playful, rounded, warm |
| Documents | System default | Markdown rendering |
