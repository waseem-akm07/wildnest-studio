## Character Engineering Checklist

Every character design must satisfy the **8-Gate Character Audit**:
1. Kindchenschema proportion check (1:1 head-to-body ratio)
2. 3-Color palette lock (60% base, 30% accent, 10% pop)
3. Scavenged accessory lock (e.g. twist-tie bowtie)
4. Core flaw & ego-reality gap established
5. OCEAN Big Five profile documented
6. Non-verbal 8-sound vocal bank defined
7. 360-degree turnaround sheet approved
8. Black silhouette recognition test passed
