## Structure

Each episode gets a folder named by its Episode ID:

```
episodes/
├── EP-001/                  ◄── Pilot: "The Grand Opening Chaos"
│   ├── 00_Episode_Brief.md  ◄── Creative brief + production goals
│   └── Production_Checklist.md ◄── Step-by-step production checklist
├── EP-002/                  ◄── (Future)
└── ...
```

## How to Create a New Episode

1. Copy the master template from `docs/05_Story_Bible/01_Episode_Template.md` (EP-TEMPLATE-001)
2. Create folder `episodes/EP-XXX/`
3. Paste as `00_Episode_Brief.md` and fill in all placeholders
4. Follow the 14-stage production pipeline (WSPW-001)
