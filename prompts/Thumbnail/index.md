> **Purpose:** Reusable prompt templates for generating high-CTR YouTube thumbnails.

## The 3-Element CTR Rule (from ART-001)

Every thumbnail must follow this composition:

```
60% — Extreme close-up of character showing INTENSE emotion
30% — High-contrast vibrant background (complementary color)
10% — One high-stakes prop (the conflict object)
```

## Text Rules

- Maximum **2 bold words** in rounded 3D yellow typography
- Text must be readable at 16×16 pixel scale (mobile feed)
- Never obscure the character's face or emotional expression
