# Templates — Reusable Document Templates

> **Purpose:** Master templates for creating new documents, episodes, characters, and production briefs.

## Available Templates

| Template | Source Location | Use Case |
| :--- | :--- | :--- |
| Episode Production Template | `docs/05_Story_Bible/01_Episode_Template.md` (EP-TEMPLATE-001) | Creating new episode briefs |
| Character Profile Template | `docs/04_Characters/00_Character_Bible.md` §9 | Creating new character profiles |
| Production Brief Template | `production/current/CHR-001/00_Brief.md` (reference) | Creating new production sprint briefs |
| Changelog Entry Template | `docs/CHANGELOG.md` §6 | Recording new version entries |
| Research Whitepaper Template | `research/Whitepaper_Template.md` | Writing new market research papers |

## How to Use

1. Find the template you need from the table above
2. Copy it to the appropriate destination folder
3. Replace all `[INSERT ...]` placeholders with actual content
4. Never modify the original template — always copy first
